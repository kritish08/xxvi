# Audio asset provenance

## Music (`music/menu.mp3`, `tense.mp3`, `game.mp3`, `triumph.mp3`)

All four loops are the repo author's own output from Google Gemini's
music generation, prompted and selected by the author specifically for
this project. They are not licensed third-party stock tracks and carry no
external attribution requirement. They ship in this repository and are
redistributed under the repository's own [MIT licence](../../../LICENSE) —
same terms as the code, copyright (c) 2026 Kritish.

See `music/README.md` for what each track is used for and the technical
constraints (length, mix level, looping) a replacement track would need to
meet.

## Narration (`narration/boot.mp3`, `install-1.mp3`, `install-3.mp3`,
`platinum.mp3`)

These four lines are OpenAI TTS output (`gpt-4o-mini-tts`, then
`gpt-audio-1.5` with heavy delivery direction, in two separate generation
passes), generated by the repo author and shipped the same way as the
music: redistributed under this repository's MIT licence. Per OpenAI's
usage terms, output generated through the API belongs to the user who
generated it, so redistributing it here under the repo's own licence is
consistent with those terms — this is not third-party content requiring
separate attribution.

**Narration is currently disabled** (`NARRATION_ENABLED = false` in
`web/src/lib/audio.ts`), so none of these four files are audible in the
shipped build even though they remain in the repo and the playback
mechanism around them is fully wired (flip the flag to bring it back —
nothing else needs to change).

Why: two full generation passes were rejected on quality before the flag
was set. Both were also judged wrong on a more basic level — the note
that decided it was "I thought of PS5, you created 1989's Wii". A
console that narrates itself (Wii, Kinect, early smart-TV UIs) is exactly
what this project set out not to be; a PS5's boot is a tone and a hum,
not a sentence, and no amount of better delivery on the TTS moves it out
of that category. Synthetic speech also degrades badly through Discord's
codec, which is the only way the recipient would ever have heard it live.
Every narrated line already has an on-screen text equivalent (install
subtitles, boot status text, the trophy toast), so disabling narration
loses nothing functionally — only the voice.
